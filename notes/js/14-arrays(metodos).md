
# 🚀 Métodos de arrays


## ✍✂ Adicionar e Remover

1) `push()`: Adiciona um ou mais itens ao final do array;
2) `pop()`: Remove o último elemento do array;
3) `unshift()`: Adiciona um item no início do array;
4) `.shift()`: Remove o primeiro elemento do array.


## 🔍💫 Buscar e Transformar

1) `some()`: Percorre o aray e verifica se este item existe (retorna true ou false);
2) `includes()`: Verifica se um determinado valor existe no array (retorna o próprio elemento);
3) `map()`: Percorre o array e retorna um novo array transformado (incorporado numa variável);
4) `filter()`: Filtra os elementos criando um novo array apenas com os itens que passaram no teste;
5) `find()`: Retorna o primeiro elemento que satisfaz a condição procurada;
